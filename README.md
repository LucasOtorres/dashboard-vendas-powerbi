# 📊 Dashboard de Vendas | Power BI

Dashboard interativo de vendas desenvolvido no **Power BI**, com indicadores gerais, análise temporal e comparativos por gênero, marca e região.

![Prévia do dashboard](dashboard.png)

## 🎯 Objetivo

Transformar dados brutos de vendas em um painel visual, claro e interativo, que ajude a responder perguntas de negócio como:

- Quanto estamos faturando e quantos clientes atendemos?
- Como o faturamento evolui ao longo dos meses?
- Qual o perfil de vendas por gênero?
- Quais marcas e regiões têm maior desempenho?

## 🧩 O que o dashboard contém

| Visual | Informação |
|---|---|
| Cartões | Indicadores globais: faturamento total e quantidade de clientes |
| Gráfico de área | Faturamento mensal |
| Gráfico de rosca | Vendas por gênero |
| Gráfico de barras | Faturamento por marca |
| Mapa | Faturamento por região |
| Filtros interativos | Exploração dinâmica dos dados em todos os visuais |

## 🛠️ Tecnologias e conceitos aplicados

- **Power BI Desktop**
- **DAX** (medidas, incluindo `DISTINCTCOUNT` para contagem de clientes únicos)
- Organização e tratamento de dados
- Visualização de dados e storytelling
- Hierarquia visual (leitura em Z) e definição de paleta de cores

## 🚀 Como abrir o projeto

1. Instale o [Power BI Desktop](https://powerbi.microsoft.com/desktop/) (gratuito).
2. Baixe o arquivo `.pbix` deste repositório.
3. Abra no Power BI Desktop e, se solicitado, atualize o caminho da fonte de dados.
